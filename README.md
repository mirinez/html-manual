# ✦ HTML Manual Básico – Proyecto de Estudio

## ✧ Sobre este proyecto

Este archivo HTML es un manual práctico creado para estudiar y entender la estructura básica de HTML.

No utiliza frameworks ni JavaScript externo.  
El objetivo principal es comprender cómo funciona cada etiqueta, cómo se estructura una página y qué significa cada atributo.

Está pensado como una guía visual y explicativa para repasar los fundamentos de HTML.

---

## ✧ Objetivos de aprendizaje

Este proyecto sirve para practicar y entender:

- La estructura básica de un documento HTML (`<!doctype>`, `<html>`, `<head>`, `<body>`).
- El uso de etiquetas semánticas como `<header>`, `<main>`, `<section>`, `<footer>`, `<nav>`.
- Elementos de texto (`<p>`, `<strong>`, `<em>`, `<small>`, etc.).
- Enlaces internos y externos (`<a>`).
- Imágenes, audio y video (`<img>`, `<video>`, `<audio>`).
- Listas ordenadas y no ordenadas (`<ul>`, `<ol>`, `<li>`).
- Tablas (`<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`).
- Formularios e inputs (`<form>`, `<input>`, `<select>`, `<textarea>`, `<button>`).
- Metaetiquetas importantes (`charset`, `viewport`, `robots`).
- Favicon y configuración básica del `<head>`.

---

## ✧ Qué contiene la página

La página está organizada en secciones claras:

1. Texto básico y formato.
2. Multimedia y enlaces.
3. Listas.
4. Contenedores y semántica.
5. Tablas.
6. Formularios.
7. Favicon.

También incluye:

- Navegación interna mediante anclas (`href="#id"`).
- Estilos CSS embebidos dentro de `<style>`.
- Comentarios explicativos dentro del código.

---

## ✧ Tecnologías usadas

- HTML5.
- CSS básico (embebido en el documento).

---

## ✧ Propósito

Este proyecto no busca diseño avanzado ni funcionalidad compleja.

Su propósito es entender:

- Cómo se construye una página web desde cero.
- Qué hace cada etiqueta.
- Por qué es importante la estructura semántica.
- Cómo se conectan atributos y elementos.

Es un ejercicio de fundamentos, enfocado en comprender la base antes de avanzar a CSS avanzado o JavaScript.
